openPOE2 is an independent, from-scratch engine written in Rust. It reads a legitimately installed copy of Path of Exile 2 and aims to run it fully offline — no servers, no accounts.

Roadmap

The goal is a faithful reimplementation. Everything that lives in the game files can be matched exactly; server-side behaviour (zone generation, monster AI, loot, damage resolution) is not stored in the client and has to be reconstructed from data and observation, so it will be an approximation.

  1. Bundle & index readerOodle-compressed bundles, 4.2 M-file path index.
    done
  2. Data tables.datc64 reader with schema validation; 19 tables still being re-fitted.
    in progress
  3. TexturesDDS (BC-compressed) decoding to PNG; icon sheets driven by data tables.
    done
  4. Models & animationsMeshes load (.fmt v9, .smd v3, verified by rendering); older mesh versions, skeletons (.ast), animations and tiles (.tgt) next.
    in progress
  5. Viewerwgpu renderer for zones and characters.
    planned
  6. Offline game coreMovement, skills, stats, items, a first playable zone.
    planned
